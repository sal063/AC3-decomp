# AC3 Native Engine

A decompilation of Ace Combat 3: Electrosphere (PS1, Japanese release) running as a native Windows program. The game code is rewritten in C++ and drawn with Vulkan.

You need your own disc images.

## Features

- Runs the whole game from the original two discs
- Internal resolution up to 8x
- Anti aliasing
- Widescreen (16:9, 16:10, 21:9)
- 60 FPS flight
- Perspective correct textures, no polygon wobble
- Bilinear ground textures
- Longer view distance
- New water
- Fog toggle
- Depth sorted aircraft models
- HD aircraft texture packs with lighting
- English translation through the Team NEMO patch
- Modern analog stick controls
- Keyboard and gamepad
